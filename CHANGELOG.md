# Changelog

Notable changes to shairkindle. Experimental software; versioning is loose.

## v0.1.0 — initial release

First public release. AirPlay-1 (RAOP) audio receiver for the jailbroken Kindle
Keyboard (K3): stream from an iPhone/iPad/Mac or iTunes/Apple Music to the K3's
built-in speaker or headphone jack, with an e-ink now-playing card (cover art,
title/artist) and the Kindle's page buttons relaying play/pause/next/prev to the
sender over DACP. Self-installing signed Kindlet; no usbnet required.

See the [README](README.md) to install.
